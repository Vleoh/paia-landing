# PAÍA Landing

Landing page estilo "link in bio" para Instagram.

## Editar enlaces

Los 4 enlaces estan en `index.html` dentro del bloque `<nav class="links">`.

- `Ver menu`
- `Reservar mesa`
- `Pedir por WhatsApp`
- `Como llegar`

## Estructura

- `index.html`: contenido principal
- `styles.css`: estilos
- `public/img/logo.png`: logo de PAÍA

## Deploy en Vercel

1. Subir este repo a GitHub (`Vleoh/paia-landing`).
2. Importar el repo en Vercel.
3. Framework preset: `Other` (sitio estatico).
4. Build command: vacio.
5. Output directory: vacio.
